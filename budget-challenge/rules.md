# Budget Challenge — Rules

## Overview

A Secret Santa-style Commander format. One player (the **challenger**) assigns a color wedge; the other (the **challenged**) builds a deck within those constraints.

---

## Rules

### Budget
- **65 € total** (card prices at time of challenge)
- Basic lands are free and excluded from the budget

### Color Wedge
- The challenger assigns any of the 10 three-color wedges (e.g. Jund, Esper, Naya…)
- The challenged may build with **any color combination within that wedge**
- Examples for Jund (BRG): mono-B, mono-R, mono-G, BR, BG, RG, or BRG
- **Colorless commanders are not allowed**

### Commander Restrictions
- The top 10 EDHREC commanders for the chosen color combination are **banned as commander**
- See [edhrec_top10_commanders.md](edhrec_top10_commanders.md) for the full reference list

### Bracket
- Target: **Bracket 2**
- No game changers (per the official Commander bracket system)

## General Banlist

### Banned — General Purpose Tutors
Cards that search for any card without meaningful restriction:

| Card | Notes |
|------|-------|
| Demonic Tutor | |
| Vampiric Tutor | |
| Imperial Seal | |
| Grim Tutor | |
| Diabolic Tutor | |
| Dark Petition | |
| Mastermind's Acquisition | Also a wish |
| Beseech the Mirror | |

### Banned — Type-Only Tutors
Cards that search any card of a broad type with no further restriction:

| Card | Searches for |
|------|-------------|
| Worldly Tutor | Any creature |
| Sylvan Tutor | Any creature (top of library) |
| Mystical Tutor | Any instant or sorcery |
| Personal Tutor | Any sorcery (top of library) |
| Solve the Equation | Any instant or sorcery |
| Enlightened Tutor | Any artifact or enchantment |
| Entomb | Any card (to graveyard) |

### Ambiguous — To Be Decided Per Challenge
These search for any card but come with a significant drawback. Discuss and agree before the challenge starts:

| Card | Notes |
|------|-------|
| Gamble | Searches any card; random discard |
| Scheming Symmetry | Searches any card; opponent also tutors |
| Wishclaw Talisman | Searches any card; passes talisman to opponent |

---

## What Is Allowed

Tutors with a genuine restriction beyond card type are **legal**. Examples:

| Card | Restriction |
|------|-------------|
| Trinket Mage | Artifact with CMC ≤ 1 |
| Recruiter of the Guard | Creature with power ≤ 1 |
| Fierce Empath | Creature with CMC ≥ 6 |
| Buried Alive | Up to 3 creatures; goes to graveyard |
| Fauna Shaman | Creature; requires discarding a creature |
| Chord of Calling | Creature with CMC ≤ X |
| Finale of Devastation | Creature with CMC ≤ X |
