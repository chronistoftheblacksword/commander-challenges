# Commander Challenges

A collection of Commander format challenges for a group of friends — each one a creative constraint disguised as a ruleset.

**Live site:** https://chronistoftheblacksword.github.io/commander-challenges/

---

## The 65€ Budget Commander Challenge

Leave your expensive staples at the door.

Each player is assigned a challenger via Secret Santa draw. The challenger picks a three-color wedge; the challenged builds any color combination within it — for 65€, with a commander nobody saw coming.

**Key rules:**
- 65€ budget (Moxfield price, cheapest printing, basics free)
- Top 10 EDHREC commanders per color combo banned from the command zone
- No free tutors; constrained tutors legal
- Bracket 2 power level

Full rules and banned list: [`budget-challenge/challenge.md`](budget-challenge/challenge.md)
